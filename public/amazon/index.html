One shared production model · two ways to work

The model reasons; application logic validates.

Director Agent · command surface

Creative orchestration within constraints

  • Interprets the brief, retrieves guidance and asks only decision-changing questions.
  • Proposes approved production actions against the same state the human sees.
  • Cannot approve generation, spend or external release.
Visual production workspace · shared state

Production state beyond the Agent interaction

  • Maintains the scene, command history and approval evidence.
  • Application logic handles versions, cost boundaries, undo and audit.
  • Blocking is working; Shot Board and multi-take review are next.
Shared contract: manual controls and the Director Agent operate the same production state and history. Agent interaction never substitutes for inspecting the work.

Orchestration case

One producer-led pipeline from concept to accepted master.

Prompt Builder · native product film

Five generated shots. One continuous-take illusion.

  • Eric set the physical-machine concept, visual vetoes, spend gates and final approval.
  • Product truth, director packet and prompt audit preceded paid generation.
  • GPT Image 2 style lock → five Gemini Omni segments via Runway MCP → audio rebuild → native HyperFrames 0.7.72 post.
Continuity engineering · measured result

Continuity was designed, measured and repaired

  • Independent start frames produced a visible seam around 0.635 SSIM.
  • True-last-frame handoffs, a continuity contract and deterministic repair raised adjacent seams to about 0.989–0.997.
  • Final: 32s · 1280×720 · 24fps · 768 frames · whole-master ACCEPT.

One-take illusion—not a literal single generation. HyperFrames was the native post/information layer, not the base-image generator. Open Prompt Builder →
